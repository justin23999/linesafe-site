LineSafe Support

Help with LineSafe — Pipeline Survey & Longitudinal Profile.

Current version 1.0.0
Platforms Android, Windows desktop
Support email linesafe.app.support@gmail.com

General support

For questions about using LineSafe, email linesafe.app.support@gmail.com. Please describe what you are trying to do and which platform you are using, Android or Windows.

You can check your installed version from the About button on the LineSafe home screen.

Bug reports

If something does not work as expected, please include:

  • Your LineSafe version
  • Your device model and Android version, or your Windows version, where relevant
  • A clear description of the problem
  • The steps to reproduce it
  • A screenshot, if it helps show the problem

Clear steps to reproduce the problem are the most useful part of a bug report.

Feature requests

Suggestions for future versions are welcome. Tell us what you would like LineSafe to do and how it would fit into your survey or drafting work. Requests are reviewed, but we cannot promise that a particular feature will be added.

File and export issues

For problems with Excel import or export, PDF longitudinal profile export or AutoCAD DXF export, please describe:

  • Which file type is affected (Excel, PDF or DXF)
  • Whether the problem happens during import, during export, or when opening the file in another program
  • The name and version of the program you opened the file with, if relevant
  • Any error message shown

Please do not send confidential project files unless it is necessary to investigate the problem and you are comfortable doing so. Where possible, reproduce the issue with a small test project that contains no confidential information, or remove sensitive details before sending.

Privacy

LineSafe stores your projects locally on your device and does not send them to us, so we cannot see or recover your projects. For details, read the Privacy Policy.
